# Агрегатор гостиниц — демо-версия для портфолио

Дипломный проект (Нетология). Бэкенд на Nest.js: бронирование, чат в реальном времени (WebSocket), ролевая модель. 


**Статус:** демо-версия для рекрутеров (готовые тестовые аккаунты, быстрый запуск через Docker).


## Стек
- Node.js, Nest.js
- MongoDB
- WebSocket, Passport.js, bcrypt.js
- Docker

## Быстрый запуск (Docker)
```bash
docker run -p 3001:3001 -it --rm gronik4/diploma-project_on_nodejs:v1.2.15
```  
После запуска проект будет доступен по адресу: http://localhost:3001.
